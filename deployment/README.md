# Carl Mod EXILED 部署包

使用 `build/Install-CarlMod.ps1 -ServerRoot <服务器目录>` 安装。脚本会把 `Carl Mod Server` 的完整服务端内容同步到指定目录，把 `CarlMod-AppData` 同步到 `%APPDATA%\CarlMod-EXILED`，并写入正确的 `exiled_directory_path`。

部署包中的游戏文件来自 `004vser_完整服务端_2026-10-04(1)\004vser`，EXILED 文件来自工作区 `Exiled12.0.1`，插件文件为经过历史启动日志验证的 Carl Mod `Carlfrellett` 2.1.0 程序集。
